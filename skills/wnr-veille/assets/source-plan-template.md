# Modèle — plan de sources (soft-gate)

Présenté en UN message compact avant de lancer les recherches. But : rendre le cadrage visible et corrigeable en un coup d'œil, sans friction. Remplace les `<…>` ; garde-le court.

---

**Veille : `<sujet / feature>`**

**Catégories croisées** (les marchés où le sujet joue vraiment) :
- `<catégorie 1 — l'évidente>`
- `<catégorie 2 — adjacente, dérivée des sorties>`
- `<catégorie 3 — l'angle mort / le différenciant, si repéré>`

**Sources retenues, par catégorie** (primaire d'abord) :
- `<catégorie 1>` → `<source primaire>`, `<source secondaire>`
- `<catégorie 2>` → `<source primaire>`, `<source secondaire>`
- `<catégorie 3>` → `<source primaire>`

**Écartés (pas pris pour vérité)** : `<ex. listicles SEO — servent juste à lister les acteurs>`, `<pages marketing comme neutres>`, `<mémoire sur les prix/modèles>`.

**J'enchaîne la recherche sur cette base — dis-moi si tu veux redresser ou ajouter une source.**

## Exemple rempli (agent de création de visuel)

**Veille : agent Designer spécialisé création de visuel**

**Catégories croisées** :
- Générateurs de carrousel LinkedIn (l'évidente)
- Text-to-infographic IA (dérivée : le schéma produit un poster)
- Critique de design assistée par IA (l'angle mort — quasi vide côté concurrence, donc différenciant)

**Sources retenues, par catégorie** :
- Carrousel → pages produit+pricing de ContentDrips/Taplio/Supergrow, avis négatifs G2
- Text-to-infographic → Napkin.ai, Canva (pages produit), model cards fal.ai/Ideogram
- Critique de design → recherche ciblée (absence = finding), Dribbble/Awwwards pour la référence qualité

**Écartés** : listicles « 10 best carousel makers 2026 » (juste pour lister les acteurs), pages marketing comme évaluation neutre, ma mémoire sur les prix.

**J'enchaîne — dis-moi si tu veux redresser.**
